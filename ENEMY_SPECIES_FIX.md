# Enemy Species Visual Fix

Enemy fish are now visually distinct by size tier instead of only changing color:
- Tiny = Guppy (slim body, small fins)
- Small = Clownfish (white bands)
- Medium = Pufferfish (round body + spikes)
- Large = Angelfish (tall body + long fins + stripes)
- Huge = Shark (shark silhouette, dorsal fin, gills, mouth)
- Boss = Deep-sea monster/whale silhouette with lure, large eye and teeth

Gameplay collision sizes, movement, spawning weights, score and progression behavior are unchanged.
All rendering is centralized in `EnemyFishRenderer.js`.
