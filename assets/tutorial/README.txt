HUNGER FISH — TUTORIAL SCREENSHOTS
====================================

Each tutorial panel has a manual screenshot slot.

Put your screenshots in this folder, then set the matching `image` field in:
js/ui/UIManager.js -> this.tutorials

Examples:
assets/tutorial/pacific-1.png
assets/tutorial/pacific-2.png
assets/tutorial/pacific-3.png
assets/tutorial/inferno-1.png
assets/tutorial/inferno-2.png
assets/tutorial/toxic-1.png
assets/tutorial/toxic-2.png
assets/tutorial/abyssal-1.png
assets/tutorial/abyssal-2.png
assets/tutorial/abyssal-3.png
assets/tutorial/abyssal-4.png

Example:
image: 'assets/tutorial/pacific-1.png'

If `image` is left as '', the game displays a dashed SCREENSHOT AREA placeholder.
